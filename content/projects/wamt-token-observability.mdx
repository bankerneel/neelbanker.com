## Problem

Token use across coding agents is hard to see while it happens. Limits, history and cost live in different places, and chat on other devices counts toward the same cap without showing up locally. The useful view is one that never sends the data anywhere else.

## Approach

Build a local, read-only observation layer around three sources: T3 Code's SQLite state, Claude Code JSONL transcripts and Codex session files. Read metadata only. Titles, models, statuses, tool names, times and token counts are enough; message text, tool inputs and outputs, commands and file paths never leave the parser. One Rust binary compiles the page in, binds to 127.0.0.1 and makes no outgoing requests.

## Architecture

- The server opens the T3 database in SQLite read-only mode with short read transactions, and tails transcripts from the last byte seen. Source folders are never written to, locked or copied, and nothing under the secrets directory is read.
- Live state is streamed to one page over Server-Sent Events at `/events`, with small JSON endpoints for a thread drill-down, a 10-minute token timeline and a `/api/brief` summary.
- The 5-hour plate opens a window at the first request after the previous one closed and lasts five hours; T3-recorded resets override the guess. Claude Code's `rate_limits` replace the estimate when the status line is installed.
- Only `.state/` is written: transcript offsets, thread launch links, daily totals older than the week, the two Claude limit percentages and a log. Deleting it is always safe.
- A strict Content Security Policy, `nosniff`, a loopback-only bind and a Host check keep the page local. Fonts, the logo and the favicon are compiled into the binary.

## Outcome

- One Rust binary serves a single dashboard on `127.0.0.1:7317`, with compiled-in assets and no outbound requests.
- Live threads and subagents show model, current step, context fill and tokens, with a row drill-down into runs, tool counts and a 10-minute timeline.
- A 5-hour plate with a 30-minute run-out forecast, a weekly meter and Codex's own limit line.
- 30-day history, PRs with CI checks, spoiled cache leftovers and API-equivalent dollars by project, with copy and CSV export.
- Diet tips name the threads behind heavy contexts, peak concurrency, marathon sessions and spoiled cache without reading message content.

## Lessons

A local tool earns trust by being boring about data: read-only sources, loopback only, metadata only, and a fixed set of files it writes. The local estimate cannot see claude.ai chat or other devices, so the status line integration matters more than a cleverer guess. Demo mode with synthetic fixtures makes it safe to screenshot and share the page without exposing real work.
